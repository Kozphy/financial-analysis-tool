# Output Directory

Generated artifacts are written here.

```text
output/
├─ charts/
│  ├─ profitability_trends.svg
│  └─ financial_position_trends.svg
└─ reports/
   ├─ financial_summary.json
   └─ executive_summary.md
```

The folders are tracked with `.gitkeep` files. Generated artifacts are ignored by git.
