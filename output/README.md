# Output Directory

Generated artifacts are grouped by purpose:

```text
output/
|-- financial/   # JSON summaries from the financial workflow
|-- charts/      # SVG charts generated from financial analysis
|-- backtests/   # JSON reports generated by the quant workflow
`-- logs/        # Optional local logs or ad hoc run artifacts
```

These folders are kept in git as empty placeholders so the repo feels organized, while generated files remain ignored by default.
