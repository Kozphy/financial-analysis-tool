# Financial Analysis Tool

A Python project for analyzing company financial performance using structured financial data.

## Project Overview
This project evaluates company performance by calculating key financial metrics such as:

- Revenue growth
- Gross margin
- Net margin

It also visualizes financial trends to support business analysis and decision-making.

## Features
- Load financial statement data from CSV
- Calculate revenue growth rate
- Calculate gross margin and net margin
- Generate trend charts for revenue and profit

## Tech Stack
- Python
- Pandas
- Matplotlib
